# অফলাইন অ্যাপ: আসল ফোনে যাচাইয়ের তালিকা (T2.7)

চ্যারিটি এন্ড সোশ্যাল সার্ভিস ডিপার্টমেন্ট · ERP · Phase 2 গেটের আগে, প্রকল্পের মালিক নিজে করবেন

Claude Code আসল ফোনে অ্যাপ চালাতে পারে না। অফলাইনের কাজ, ইনস্টল আর ফোনের স্টোরেজের আচরণ Android আর iPhone-এ আলাদা, তাই এই তালিকাটা দুটো ফোনে হাতে-কলমে করতে হবে। প্রতিটি ধাপের পাশে "যা হওয়ার কথা" মিলিয়ে দেখুন; না মিললে শেষের টেবিলে লিখুন। ফলাফল `docs/testing/` ফোল্ডারে রাখা হবে (এই ফাইলের শেষ অংশে, বা আলাদা ফাইলে)।

## ১. আগে যা লাগবে

- যে কম্পিউটারে সার্ভার চলছে, ফোন দুটো তার একই Wi-Fi-তে। সার্ভার চালু: `docker compose up -d postgres minio mailpit`, তারপর `pnpm dev`। ফোন থেকে ঠিকানা: `http://<কম্পিউটারের IP>:3000` (ইনস্টলের জন্য https লাগতে পারে; তখন staging ঠিকানা ব্যবহার করুন)।
- ডেমো ডেটা নতুন করে: `pnpm db:reset`, `pnpm db:seed --set all`, `pnpm db:load-locations`।
- স্বেচ্ছাসেবকের অ্যাকাউন্ট: নমুনা স্বেচ্ছাসেবক 6, মোবাইল `01700000106`, পাসওয়ার্ড `CssDemo2026`। একটা চালু প্রকল্পে তাঁকে যুক্ত করে নিন (RPM বা হেড হিসেবে `/admin/projects` থেকে), আর স্বেচ্ছাসেবক হিসেবে নিয়মাবলিতে সম্মতি দিন।
- অফিসের দিক দেখার জন্য কম্পিউটারে `rpm.dhaka@example.org` (পাসওয়ার্ড একই)।
- সব তথ্য নমুনা। আসল কারো NID, মোবাইল বা ছবি দেবেন না।

| # | ধাপ | যা হওয়ার কথা | ফলাফল |

| A10 | ফোনে আবার Airplane mode চালু; নতুন একটা খসড়া শুরু করে প্রথম অংশ শেষ করুন; প্রোফাইল মেনু → লগআউট | "না পাঠানো কাজ আছে" সতর্কবার্তা, "তবুও লগআউট করুন" চাপলে দ্বিতীয় নিশ্চয়তা; "বাতিল" দিলে খসড়া থাকে | |
| A11 | Airplane mode বন্ধ করে নেট ফিরলে `/sync`-এ "এখনই সিঙ্ক করুন" | খসড়া অফিসে পৌঁছায়; `/sync` "সব পাঠানো হয়েছে" | |
| A12 | কম্পিউটারে হেড হিসেবে স্বেচ্ছাসেবকের প্রোফাইল → ডিভাইস → এই ফোন লগআউট করুন; ফোনে যেকোনো ট্যাব চাপুন | ফোন লগইন পাতায় ফিরে যায়; আবার লগইন করলে আগের ক্যাশ নেই (প্রকল্প তালিকা নতুন করে আসে) | |
| A13 | Chrome-এ (অ্যাপ নয়) সাইট খুলে Settings → Site settings → Storage দেখুন | সাইটটির স্টোরেজ "persistent"/সংরক্ষিত হিসেবে থাকলে ভালো; না থাকলে লিখে রাখুন | |

# INTERNATIONALIZATION

Status: outline, written in task T0.1 (2026-10-10); completed in task T0.20; implemented in task T1.5. Sources: constitution §11, blueprint B9, UX-05, design brief §2.

## 1. Languages
bn (default) and en, per-user switch, both first-class; adding a third language without rewriting.

## 2. Message catalogue
Key naming (`module.screen.element`), file layout in `packages/shared`, missing-key policy and CI check, pluralization.

## 3. Bilingual data
Which entity fields carry bn and en values (form labels, sections, options, statuses, stage names, notification templates); fallback rules.

## 4. Numbers, dates and digits
English digits everywhere (UX-05), one formatting utility, currency display (৳), date and time formats, optional Hijri date setting (off by default), time zone (Asia/Dhaka).

## 5. Fonts and rendering
UbuntuSans for Latin and digits, Bornomala for Bengali; precache in the PWA; PDF export fonts.

## 6. Localized content outside the UI
Email and SMS templates, PDF exports, error messages from the API (keys plus localized text).

## 7. Testing
Language-switch E2E journey, missing-key check, digit formatting unit tests, screenshot checks of long Bengali strings on 360 px.

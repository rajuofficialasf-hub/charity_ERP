# SCREEN INVENTORY

Status: outline, written in task T0.1 (2026-10-10); completed in task T0.19; mockups in task T0.19b under `docs/ui/mockups/`. For every screen: purpose, roles, device priority, data shown, actions, states (empty, loading, error, offline, pending sync), components used, blueprint section, phase.

## 1. Shared
Login and registration (two OTP steps); role-based home ("My Work", A4); notifications inbox and sync status; language switch; profile and edit request.

## 2. Volunteer (phone first)
Home with offline banner and needs-attention cards; my projects and consent flow; new application with NID lookup, auto-fill, locked fields, blocklist message, duplicate warning; my applications by status and detail with step timeline; today's distribution bulk screen with camera, photo state and stock summary; today's class; today's construction (paid volunteer); expense claim; team assignment.

## 3. Officials (responsive, 360 px)
Review queue with score and quota bars; application detail with timeline, change log, family-duplicate warning, approve/waitlist/reject, field unlock; volunteer tab and profile (permissions, work summary, ratings, categories, animal allocation, blocklist, transfer); beneficiary tab and 360° profile with merge; issue log; site verification; payments and expense verification; document register and deficiency report; handover.

## 4. Management (responsive)
Project dashboard (progress first); program, central and dawah dashboards; monitoring control centre with alerts; work summaries; audit log viewer.

## 5. Setup (desktop first)
Program and project setup with component toggles and draft save; form builder with section library, field settings, live preview and versions; templates; permission panel; admin settings (thresholds, nisab, providers, holiday calendar); document checklist editor; rating criteria; quotas and scoring criteria.

## 5a. Media Team (responsive; O-28)
Media tab: media work list with "add beneficiary" (select from the nationwide beneficiary list, sensitive fields masked), per-beneficiary media status (planned / in progress / published), story editor with writing area, channel and publication date, publishable photo list gated by consent.

## 6. Project-specific
Qurbani donor list and import, animal allocation and photos; dawah tracking view and exams; construction stages; safe-water advance and vouchers; tree-planting public form.

## 7. Mockup set for T0.19b
The 14 pilot screens listed in `docs/ui/DESIGN_BRIEF.md` §6, with later-phase screens mocked at the start of their phase.
